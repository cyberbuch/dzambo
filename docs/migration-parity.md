# Миграция ytbuch → dzambo

## Цел

Пренасяне на цялата счетоводна логика на **ytbuch** върху нов стек, с пазене
на бизнес правилата и API договора. Няма продуктови данни — схемата е чиста.

## Ключови решения

| Въпрос | Решение |
|--------|---------|
| Backend стек | Rust + Axum 0.8 + Diesel + PostgreSQL (една база, без SQLite/sync) |
| Desktop | Tauri v2 тънък клиент към сървъра (винаги online) |
| Frontend | **оригиналният Next.js фронт**, пренесен едно към едно (API договорът се запазва) |
| SAF-T | мапинг на свободния сметкоплан към НАП номенклатурите |
| Данни | без миграция на данни; демо seed |

> Минималният Vite/shadcn фронт беше отхвърлен („няма нищо общо с изходния“).
> Оттук пренесохме оригиналните екрани.

## Разлики спрямо ytbuch

- **База:** Octo/YottaDB → PostgreSQL (истински транзакции, FK, IDENTITY,
  индекси). Octo хаковете (escape-backslash, `MAX(id)+1`, ръчен rollback)
  са махнати.
- **Активна фирма** се резолва от потребителя (superadmin: stored/1; другите:
  членство).
- **Справки** са нови (i128 стотинки), не Octo пагинация.
- **Frontend** е същият код, но върви срещу новия API (proxy).

## Паритет

- Покритие на endpoint-и: **0 оставащи gaps** (одит на всички `/v1/` пътища,
  които фронтът вика).
- SAF-T: 3 режима, 0 XSD грешки.
- Всички модули на ytbuch имат реализация: фактури, дневник, ДДС, НАП файл,
  склад, ДМА, производство, дивиденти, банки, справки, роли/одит, auth flows,
  VIES, КН8, scans.

## Известни ограничения / по желание

- **Mistral AI** (OCR/класификация) е опционално — изисква `MISTRAL_API_KEY`.
  Без него cn8-suggest работи от локалния каталог, scans/extract връща 422.
- **Address split** в `/v1/addresses/parse` е локална евристика (без Mistral).
- **Desktop native команди** (печат/файлове през platform.ts) са scaffold-нати
  (`probe`); основната функционалност е уеб-базирана.
- Стари тестови артефакти от dev се трият; няма commit за DB конфигурация.

## Процес

Модул по модул; батериите зелени преди пуш; UI на живо при frontend промяна;
одит на паритета („коректността веднага, финното за края").
